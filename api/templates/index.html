API reference

  • GET  /health — liveness + database check
  • POST /endpoints — register a subscriber URL (US-1.1)
  • GET  /endpoints — list subscribers
  • POST /events — publish an event, returns 202 + fans out (US-1.2)
  • GET  /deliveries?status=dead&limit=&offset= — filterable delivery log (US-3.1)
  • GET  /deliveries/stats — per-status counts
  • POST /deliveries/<id>/replay — re-queue a dead delivery (US-3.2)
POST /events and POST /endpoints are POST-only by design — they are publisher actions, not browsable pages. Opening them with GET returns 405 Method Not Allowed.
